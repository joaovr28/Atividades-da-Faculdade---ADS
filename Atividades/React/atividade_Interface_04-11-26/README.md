# Navegação e Interfaces com React

Este projeto é uma atividade prática de desenvolvimento front-end com o foco em implementar uma **Single Page Application (SPA)** utilizando **React** e **TypeScript**. A aplicação demonstra a construção de uma interface de usuário modular e a navegação fluida entre diferentes telas através de roteamento dinâmico.

## 🚀 Funcionalidades

- **Roteamento Dinâmico:** Utilização da biblioteca `react-router-dom` para navegação instantânea entre as páginas (Home, Login, Contatos, Serviços e Mais Informações) sem recarregamento do navegador.
- **Interface Estilizada:** Barra de navegação customizada com CSS global, adotando um tema escuro (Dark Mode) moderno. Inclui alinhamento responsivo via Flexbox, efeitos de transição (hover) e separadores visuais entre os links.
- **Componentização e Organização:** Estrutura de arquivos limpa, isolando as rotas no arquivo de inicialização (`main.tsx`) e agrupando as páginas da aplicação em um diretório dedicado de visualizações (`Views`).

## 🛠️ Tecnologias Utilizadas

- **React** (com TypeScript)
- **React Router DOM** (Gerenciamento de rotas e componentes de Link)
- **CSS3** (Estilização de layout e componentes visuais)
- **Vite** (Ferramenta de build e servidor de desenvolvimento)
